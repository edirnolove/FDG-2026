## 📝 Descripción del Curso

**Fundamentos de Gestión de Datos** desarrolla las bases para comprender, organizar, consultar, preparar y analizar datos en contextos empresariales, y para reconocer la importancia de su calidad, seguridad y gobierno.

El recorrido empieza con gestión de datos, SQL y modelado relacional. Luego aborda Python y pandas, limpieza y regresión lineal simple y múltiple en la semana 6, clustering en la semana 7 y la evaluación Pa2 con la exposición de PMD1 en la semana 8. La segunda mitad trata administración, ETL, metadatos, arquitectura, calidad y gobierno de datos.

Las actividades aplican los conceptos en casos reales con **Google Colab, SQLite, Python, pandas, scikit-learn, GitHub y Kaggle**. El trabajo técnico se acompaña de interpretación de resultados y conclusiones para la toma de decisiones.
